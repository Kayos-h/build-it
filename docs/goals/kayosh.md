**Why:** Kiro Crew tokens reset at month end. We use the full plan by building every model with Kiro Crew + the Blender MCP server.

**Progress:** 50 / 50 done  (CPU 14/14 · GPU 17/17 · Motherboard 19/19)

## Done means (for every model)
1. The file exists at `data/models/catalog/<path below>`.
2. Lowercase, hyphenated filename, exactly as listed.
3. Checked with a real screenshot of the model. Part counts and bounding boxes alone do not count.
4. The box is ticked here.

## How to work
- Start a brand-new chat first, so the Blender tools attach to it.
- Build in Blender, export as `.glb`, then tick the box.
- Marks: `★` = new part added to the shortlist. No mark = from the original 90-entry shortlist.
